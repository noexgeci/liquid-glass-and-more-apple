Anyag

Üveg, ami tényleg megtöri a fényt.

Minden felület saját, méretre számolt fénytörési térképet kap. A peremen a tartalom meghajlik, a közép tiszta marad, a tükröződő él követi a kurzort. Chromiumban és Electronban valódi lencse, Safariban és Firefoxban homályos üveg.

Glass

Regular

Homályosít és kiegyenlíti a fényerőt. A legtöbb vezérlő, sáv és dialógus ezt használja.

Clear

Szinte teljesen átlátszó. Fotók és videók fölé, ahol a tartalom a lényeg.

Tinted

Színezett üveg a fő műveletekhez, mint a Kész gomb.

Vezérlők

Minden, amit az iOS 26-ban megszoktál.

Nyomd meg és húzd őket. A kapcsoló, a csúszka és a szegmensvezérlő kijelölése üveglencsévé válik, és felnagyítja azt, ami alatta van.

Színek

Az iOS 26 rendszerszínei, pontosan.

Az értékek az Apple HIG oldaláról származnak. Világos, sötét és nagy kontrasztú változat, automatikusan váltva. Kapcsold át a témát fent jobbra.

Tipográfia

Dynamic Type, SF betűközökkel.

Apple eszközökön a rendszer SF Pro betűje jelenik meg a pontos 510-es és 590-es súlyokkal, máshol a rendszer alapértelmezett betűje.

Kezdés

Egy perc alatt a projektedben.

Sima HTML, Next.js, Vite vagy Electron: válaszd ki, másold be.

<!-- a <head>-be -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/noexgeci/liquid-glass-and-more-apple@main/dist/liquid-glass.min.css">
<script src="https://cdn.jsdelivr.net/gh/noexgeci/liquid-glass-and-more-apple@main/dist/liquid-glass.min.js" defer></script>

<!-- bárhol a <body>-ban -->
<button class="lg-button lg-button--prominent">Kész</button>
<label class="lg-switch"><input type="checkbox" checked></label>
# telepítés
npm install github:noexgeci/liquid-glass-and-more-apple

// app/layout.tsx
import 'liquid-glass-kit/css';
import { LiquidGlassProvider } from 'liquid-glass-kit/react';

export default function RootLayout({ children }) {
  return (
    <html lang="hu">
      <body className="lg"><LiquidGlassProvider>{children}</LiquidGlassProvider></body>
    </html>
  );
}

// app/page.tsx
import { Button, Switch, TabBar, Icon } from 'liquid-glass-kit/react';
npm create vite@latest my-app -- --template react
npm install github:noexgeci/liquid-glass-and-more-apple

// src/main.jsx
import 'liquid-glass-kit/css';
import { LiquidGlassProvider, Button } from 'liquid-glass-kit/react';

createRoot(root).render(
  <LiquidGlassProvider><Button variant="prominent">Szia</Button></LiquidGlassProvider>
);
// main.js: natív macOS üveg az ablak mögött
new BrowserWindow({
  titleBarStyle: 'hiddenInset',
  vibrancy: 'under-window',
  visualEffectState: 'active',
  backgroundMaterial: 'acrylic', // Windows 11
  backgroundColor: '#00000000',
});

// renderer: ugyanaz, mint a weben, a teljes fénytöréssel
import 'liquid-glass-kit/css';
import 'liquid-glass-kit/auto';
